# The Jorker

A human-sized robot hand that bolts onto the wrist flange of the RB-Y1M and AgiBot G2. It is tendon-driven and modular, with 5 fingers.

- Bones are printed in PLA. Pads and return springs are printed in TPU, on a Bambu P1S.
- The joints pop apart under overload and push back in by hand. Each tendon ends in a crimped loop that hooks on, so it releases too.
- docs/dimensions.md is the single source for every size. Read it before any modelling.
- cad/parts/ holds one OpenSCAD file per part (P01–P19).
- cad/assemblies/ holds the assemblies (A1–A4).
- CHANGELOG.md is the build log.
